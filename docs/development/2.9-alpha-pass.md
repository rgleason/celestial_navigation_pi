## Decisions and alpha boundary

The [Moon oblateness audit](moon-oblateness-306.md) reproduces a small real
effect but defers a production correction until ordinary altitude reduction,
the position solver and the non-spherical plotted locus can be changed
consistently. The existing WGS84 lunar-distance model is unchanged.

This remains 2.9.0.0 alpha work. Local Linux tests do not certify Windows/macOS
native appearance or every OpenGL/Vulkan driver. Those remain CI and tester
coverage, not a reason to change the stable 2.8.11 catalogue. No stable tag or
catalogue-master change is part of this pass. CI builds from the development
branch and the alpha-review PR provide the cross-platform follow-up.
