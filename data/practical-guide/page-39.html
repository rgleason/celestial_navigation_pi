6. Input Lunar Sights into Celestial Navigation Plugin

Select Celestial Navigation Icon from Open CPN Menu The Celestial Navigation opens with Celestial Navigation “Sights” displaying existing sights

View full-resolution illustration

To input a new sight, select one of 2 options.

New or Duplicate. If Duplicate, it will duplicate the highlighted sight and then Edit the Duplicated Sight. You can duplicate an Altitude sight and change it to a Lunar Sight.
